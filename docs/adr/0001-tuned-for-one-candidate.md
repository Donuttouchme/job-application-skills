# Tuned for one candidate, not generic

The skills are tuned for the repo owner's own job search: the Swiss market, English and Swiss German, and a career change into DevOps / Platform engineering. A generic toolkit cannot make the calls that matter here (how to present a career change on thin evidence, which lanes are open), and there is one user. Personal facts still never enter the repo: they live in the profile, outside version control, and the skills only assume the situation, not the data.
